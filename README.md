# huxinxiaoye.github.io

刘晋豪的个人主页与软件发布页。

## 内容

- `index.html`：个人主页与作品列表
- `diskcleaner.html`：磁盘空间分析器详情、截图与下载页
- `downloads/DiskCleaner_1.0.0_win64_portable.zip`：Windows 64 位便携版
- `assets/`：图标、样式和社交分享图

## 发布

仓库的 `main` 分支根目录直接由 GitHub Pages 提供访问：

https://huxinxiaoye.github.io/

更新下载包时，替换 `downloads/` 下的压缩包，并同步修改 `diskcleaner.html`
中的版本号、文件大小和 SHA-256。
